Featured Project

Smart AI-Based Attendance System

Manual roll calls waste class time and are easy to fake. So we built a camera-based attendance system that recognizes faces in real time and logs attendance automatically — no roll calls, no proxy attendance, no paperwork. It runs on low-cost hardware, so any classroom, lab or office can set it up in an afternoon without a big budget. It's a direct product of what we study — IoT and Cyber Security — applied to a real, everyday campus problem.

  • Low cost — built with budget-friendly components
  • Easy circuit — simple, beginner-friendly hardware design
  • Easy setup — up and running in minutes
  • Fast & responsive — real-time recognition and response
  • AI-based face recognition for accurate identification
  • Live attendance dashboard with instant updates
  • Secure cloud data storage & backup
  • Multi-device & multi-room compatibility
